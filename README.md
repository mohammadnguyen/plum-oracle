# 梅花易数 · 透明排盘

确定性梅花易数排盘：起卦、互卦、变卦、体用、五行生克、旺衰、应期逐步可查，
并导出一段可复制的「解读 Prompt」，交给你自己的 AI 工具完成解读。

**本站不调用任何 AI，没有后端，没有账号，不收集任何数据。**

## 它做什么

- **排盘是确定性的**：四种起卦法（年月日时 / 报数 / 指物方位 / 验色），纯代码推算，没有随机数。
- **每一步都能展开看**：上下卦怎么来、互卦怎么取、体用怎么判、四卦对体各是什么关系、
  净评 d 值怎么算、旺衰按哪个节令、应期走哪条路由、化解引的是哪一条经典。
- **卦爻辞逐字**：64 卦辞 + 384 爻辞取自人工核定的通行本，不靠 AI 记忆。
  未核定的单元会明确标为 `pending · 屏蔽`，而不是假装没有。
- **解读交给你的 AI**：把盘面事实与解读要求一并导出，你复制到任何 AI 工具里即可。

## 它不做什么

- 不声称、不暗示任何**预测**有效性。本站呈现的是传统象数体系的内部推演过程。
- 不替你裁决门派分歧——有分歧的地方并列标明，采用哪一说写在「门派声明」里。
- 不保证你的 AI 会遵守导出的解读要求（本站没有校验器拦它）。引文是否逐字，请对照导出文本自行核对。

## 本地运行

```bash
npm install
npm test     # 等价性对拍、黄金案例、语料覆盖、导出完整性
npm run dev
npm run build
```

## 方法保真怎么验证

排盘算法移植自同项目的 Python 参考实现，两者逐字段对拍：
Layer A 3,530 组、断事层 2,626 组、导出 Prompt 112 组，差异为零；
原书五个黄金案例（观梅、牡丹、借斧、牛哀鸣、验色）逐字段复现。
